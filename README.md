# Amanda Camp & Co — business site

Source for amandacampco.com. A static site: `index.html` (inline CSS and JS), images in `img/`, and the Command Center demo video. No build step.

## Deploy (Netlify)
Link this repo in Netlify (Site configuration → Build & deploy → Link repository). Leave the build command blank and set the publish directory to `/`.

## Notes
- `index.html` has `<meta name="robots" content="noindex, nofollow">`. Remove it when you want Google to find the site.
- Scroll reveals, count-up stats, hover effects, parallax and the video autoplay all switch off for visitors who prefer reduced motion.
- The stats and the Command Center, cash forecast and card-control images come from work done at a previous employer. Get their OK before the site goes public.
